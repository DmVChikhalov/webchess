# WebChess — обучающие веб-шахматы

Локальные шахматы в браузере со Stockfish 18 на **максимальной силе** и обучающим
разбором каждого хода: дебютная теория, идея хода, дальнейшая перспектива и сноски на
классические книги (Нимцович, Капабланка, Тарраш, Ласкер, Керес и др.).

Версия: 0.6.0.1 (стадия.фичи.изменения.сборка)

## Запуск

Дважды кликнуть `START_CHESS.cmd` — поднимет локальный сервер (Python, порт 8130)
и откроет игру в браузере. Сервер обязателен: браузеры не запускают Worker/WASM с `file://`.

## Как играть

1. **Настройка в два шага**: сначала режим → «Продолжить» → затем параметры, только
   если они нужны (цвет; для обучения — ещё выбор дебюта). У «Тренировки дебютов»
   параметров нет — она стартует сразу (цвет и дебют случайные).
   Режимы: **Тренировка** (полный разбор каждого хода), **Обычная игра** (только
   рекомендации), **Учить базовые дебюты** (см. ниже), **Тренировка дебютов**,
   **Самоучитель дебютов**.

## Учить базовые дебюты

Режим для первого знакомства с дебютом: выбираете дебют по имени (8 линий из базы
тренировок) и цвет — и тренажёр ПРЯМО говорит каждый ваш ход: «Двигай: конь g1 → f3»
с подсветкой клеток на доске и объяснением «почему» (мысль линии или теория из базы).
Соперник отвечает сам; неправильный ход не применяется — указание повторяется.
После правильного хода — подтверждение с теорией. В конце — то же информационное
окно, что и в тренировке (план, шансы, вариации, знаменитые партии).
Запуск по URL: `/?autostart=1&mode=learn&drill=<id>&color=w|b`.
2. **Вы ходите за обе стороны в любом режиме.** Ход противника можно сделать
   самому, а можно нажать **«Ходи»** — тогда лучший ход сделает Stockfish на полной силе.
3. Рекомендация движка (лучший ход) показывается всегда: стрелка на доске + панель справа
   с оценкой и главной линией. Под доской во всех режимах — виджет процентов побед
   текущего дебюта (белые·ничьи·чёрные + ожидаемый счёт за ваш цвет); в загадке
   тренировки имя дебюта в виджете скрыто.
   На каждой клетке подписано её имя (e4, d5…); над и под доской — съеденные каждой
   стороной фигуры и материальный перевес словами («+1 пешка», «+1 ферзь», «фигуры равны»).
4. В тренировке после каждого хода — разбор: качество хода (лучший/неточность/зевок),
   дебютная теория с названием варианта и кодом ECO, зачем сделан ход, перспектива
   по линии движка и книжные принципы со сносками.

## Самоучитель дебютов

Режим для отработки дебютной стратегии: ходить можно за обе стороны (чтобы разбирать
конкретные вариации), кнопка «Ходи» делает лучший ход движка за того, чей ход.
Панель «Самоучитель дебютов» с первых ходов показывает:

- **какой дебют** разыгрывается (семейство + точный вариант из базы);
- **глобальную стратегию за вас**: типовые планы, куда идут фигуры, какие линии
  вскрывать и к какому ходу («к 12–15-му ходу вскрыть линию b» и т. п.);
- **план соперника** — чем этот дебют будет бить по вам;
- **ориентиры** — короткие конкретные правила варианта;
- **выходы следующим ходом** — в какие дебюты базы ведёт каждый возможный следующий
  ход (после первого хода партии, чтобы не перечислять всю базу);
- **статистику дебютов** — полоса «победы белых / ничьи / победы чёрных» текущего
  дебюта + ожидаемый счёт за ваш цвет; выходы следующим ходом отсортированы по
  ожидаемому счёту ходящей стороны, лучший помечен 🏆. Числа — округлённые агрегаты
  больших баз мастерских партий (`FAMILY_STATS` в `js/strategies.js`), для сравнения
  дебютов между собой, а не как точная истина.

Стратегии лежат в `js/strategies.js` (~30 дебютных семейств от испанской и Найдорфа
до Лондона и Рети); выбирается самое глубокое семейство по префиксу ходов партии.
Разбор каждого хода (как в тренировке) при этом сохраняется.

## Тренировка дебютов

Режим-викторина (цвет и дебют выбираются случайно): тренажёр играет за соперника и
делает первый ход белых, если вы белые. Загадана ОДНА заранее заготовленная линия
лучших ходов — дебют вашего цвета всегда статистически сильнейший против дебюта
соперника. Ваша задача — определить дебют по первым ходам и каждый раз делать
единственный правильный ход линии.

- Неправильный ход не применяется: тренажёр говорит, какому дебюту принадлежит
  ваша попытка, но загаданный не раскрывает.
- Обучение вместо угадывания: перед каждым вашим ходом — мысль «🤔 на подумать»
  (идея хода без спойлера), с каждой ошибкой подсказки нарастают (какая фигура →
  с какого поля → на какое), а после правильного хода показывается обоснование —
  идея линии плюс теория из дебютной базы.
- Пройдя линию, вы видите шанс на победу за свой цвет и информационное окно:
  📊 шансы, 💡 основная идея, 📋 план (дебют/миттельшпиль/эндшпиль), 🔀 вариации,
  📜 история.
- У каждого дебюта — 2–3 знаменитые партии (всего 17), реальные, сверенные с
  каноническими источниками. ЦЕЛИКОМ (до последнего хода): Карпов—Каспаров 1985 (16-я),
  «Партия века» Бирн—Фишер 1956, Фишер—Спасский 1972 (6-я), Капабланка—Маршалл 1918,
  «Мона Лиза» Багиров—Гуфельд 1973, Кокрейн—Мохишундер 1851 (первая КИД в истории),
  Морфи «Опера» 1858, Легаль 1750, «Бессмертная» 1851, Стейниц—Барделебен 1895,
  Рети—Тартаковер 1910, Deep Blue—Каспаров 1997, Ротлеви—Рубинштейн 1907.
  До кульминации (с рассказом финала): Нежметдинов—Черников 1962, Фишер—Ларсен 1958,
  Спасский—Фишер 1972 (11-я), Нимцович—Сальве 1911, Алехин—Нимцович 1930.
  Кнопки партий отсортированы по совпадению с линией дебюта (глубина совпадения подписана);
  если проверенных партий для дебюта нет — честная надпись (дебют остаётся: он сильнейший
  по статистике). В конце записи партии — кнопка «🤖 Продолжить Stockfish'ом»: движок
  доигрывает позицию за обе стороны, показывая каждый ход с оценкой.
  Книжные сноски в разборе ходов ротируются (2–3 цитаты разных авторов на принцип).
  Партию можно промотать кнопками с объяснением идеи каждого хода; ходить в этот
  момент нельзя — только мотать или начать новый дебют. **В просмотре работает
  Stockfish**: на каждой позиции показывает лучший ход и отмечает, где исторический
  ход разошёлся с выбором движка.
- В фазе загадки движок молчит (стрелка/оценка раскрыли бы ответ).
- Информационное окно — в две колонки, без прокрутки.
- База тренировок — `js/drills.js` (8 линий: 4 за белых, 4 за чёрных).
  Тест: `tests/test_drill.html`; детерминированный запуск: `/?autostart=1&mode=drill&drill=<id>`.

## Устройство

| Файл | Назначение |
|---|---|
| `index.html` | Экраны настройки и игры |
| `js/app.js` | Доска, состояние партии, обёртка UCI-движка, рендер панелей |
| `js/openings.js` | Дебютная база: SAN-последовательность → название, идея, план, книга |
| `js/strategies.js` | Стратегии дебютных семейств для самоучителя: планы сторон + ориентиры |
| `js/explain.js` | Эвристический объяснитель ходов + книжные принципы + качество хода |
| `css/style.css` | Стили |
| `lib/chess.js` | Правила шахмат (chess.js 0.13.4) |
| `lib/stockfish-18-single.js/.wasm` | Stockfish 18, полная сборка (NNUE вшиты в wasm) |
| `lib/stockfish-18-lite-single.js/.wasm` | Запасная lite-сборка для слабых машин (7 МБ) |
| `lib/stockfish-nnue-16-single.js/.wasm`, `lib/nn-*.nnue` | Прежний Stockfish 16 (запас) |

Движок работает в Web Worker; анализ каждой позиции: `go depth 24 movetime 2500`.
Сила не ограничивается (никаких `UCI_LimitStrength`/`Skill Level`).

## Быстрый старт и тесты

- Автостарт партии по URL: `http://localhost:8130/?autostart=1&color=b&mode=training`
  (`color`: w|b, `mode`: training|casual|tutor).
- Отладка в консоли браузера: `window.WebChess` (состояние партии и движок).
- `tests/test_engine.html` — смоук движка (UCI), `tests/test_ui.html` — e2e полного
  цикла: рекомендация → ход → разбор → ход движка (обе шлют результат POST `/result`);
  `tests/test_tutor.html` — e2e самоучителя: авто-ответ бота, смена семейства, парный
  откат (результат пишет в DOM страницы — гонять через puppeteer/скриншот).

## Ограничения

- Однопоточная сборка WASM (без SharedArrayBuffer) — глубина ~18–24 за 2.5 с. Для
  обучения это заведомо сильнее любого клубного игрока.
- Дебютная база — ручная выборка главных линий (~70 позиций). Вне базы объяснения
  строятся эвристиками и линией движка.
